# Report Portal автотесты

Проект представляет собой автоматизированные тесты для UI и API составляющих приложения ReportPortal.

# Использованные технологии

- **Java 17** – основной язык разработки
- **Selenide** – фреймворк для автоматизации веб-тестов
- **Allure Report** – генерация детализированных отчётов
- **JUnit 5** – организация тестовых сценариев
- **Maven** – управление зависимостями и сборка проекта

# Пререквизиты

[Maven 3.9.9](https://dlcdn.apache.org/maven/maven-3/3.9.9/binaries/apache-maven-3.9.9-bin.zip)

[JDK 17.0.12](https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html)

Необходимо добавить их %_framework_name_%/bin/ в PATH.

# Что проверяют тесты

- Создание виджета при помощи UI.
- Создание дешборда при помощи API.
- Некорректный ввод данных приводит к ошибке при создании дешборда.

# Запуск

Для запуска используйте одну из следующих команд:

> mvn clean test -Dgroups=API allure:serve

Запускает все тесты в тегом API и генерирует отчет на выходе.

> mvn clean test -Dgroups=UI allure:serve

Запускает все тесты с тегом UI и генерирует отчет на выходе.

> mvn clean test allure:serve

Запускает все тесты и генерирует отчет на выходе.

> mvn allure:serve

Генерирует отчет из последних результатов.
